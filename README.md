# Visique-GUI

A native Electron + TypeScript desktop client for Visique. Users upload an Excel
file, it's sent to the Visique backend for financial analysis, and the results
are rendered as a local dashboard of KPIs, health score, and trend charts.

This is a standalone client of the Visique platform (see `Visique-Testing`) —
it calls the existing backend/analysis services directly rather than embedding
the website. See `docs/superpowers/specs/` for the design spec.

## Status

Design phase complete. Implementation not yet started.
